## 👀 About

An independent, open-ended effort to rethink distributed and concurrent
computing from first principles, searching for a most natural way to
express it. The emerging ideas are to take shape in a minimalistic,
Rust-based open-source framework for core replication and coordination
mechanisms of decentralized, distributed systems, such as BFT consensus.

For more information, please visit the [project's website](https://replica-io.dev/).

## 🌱 Status

This project is in its early stages. It's being developed entirely in
the open from day one. Stay tuned! 📡
